# meridian6.ai

Meridian6 — the AI-first digital agency for small business.
Static site (hand-coded HTML/CSS/JS), deployed to Netlify at https://meridian6.ai.

- No build step. Edit, push to `main`, Netlify deploys.
- CSS/JS are cache-busted with `?v=` params and served immutable — bump the
  version on every CSS/JS change.
- Formerly the `flint-digital` repository; renamed with the September 2026 rebrand.
